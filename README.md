# Myrandapratas — V1

Catálogo digital mobile-first, sem checkout e sem pagamento online.

## Como testar
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Teste no celular ou use o modo responsivo do navegador.

## O que já funciona
- Página inicial da marca
- Categorias
- Filtros
- Produtos fictícios
- Disponível/indisponível
- Adicionar/remover da seleção
- Contador de itens
- Total automático
- Modal "Minha seleção"
- Confirmação
- Geração de código da seleção
